# Stream Weaver

cria um reprodutor de lista m3u estilo netflix incluindo onde fica cada coisa 

estamos criando um player de m3u vejo na internet dizendo Acesse uma ferramenta de edição e criação como o M3U Playlist Builder. Adicione os links de transmissão (URLs diretas de stream) clicando em Add Stream. Insira o nome do canal ou mídia, a categoria e, se quiser, o link do logotipo (TVG Logo). Reordene os itens se precisar e clique em exportar para baixar o arquivo .m3u gerado.
